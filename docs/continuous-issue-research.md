# 持续议题补全与逐条研究队列

补全目标仍覆盖当前统一底库的每条身份。完成一批并不等于完成全量研究，也不把获取简介、结构检查或题名作者对应记为内容分析完成。

## 第二轮已发布检查点

2026-10-04 在前一版本 784 条核心问题分析基础上，新增 183 条，达到 967 条；尚缺分析 13,597 条。新增 396 个细分问题及情节依据，累计 1,676 个。四组新增记录分别为早期 31 条、1900—1979 年 61 条、1980 年后 73 条、跨年代实际资料阅读 18 条。后续检查点数量以生成元数据为准。

新增全部维持 `knowledge_added_unverified`。原作或出版社介绍已实际阅读的范围逐批说明，不将简介或章节节选冒充全书核验。19世纪使用后世重印文本时记录版本差异；短篇、合集、系列、译本和边界参照保持各自身份。熟悉内容的补充仍需要独立核对。

## 第三轮检查点

继续新增 120 条分析：早期 17 条、1900—1979 年 52 条、1980 年后 39 条、实际资料阅读 12 条。统一库累计 1,087 条已有核心问题，13,477 条待补；935 条含细分问题，共 1,927 个。自本次持续推进开始，已经新增 303 条核心分析。这仍是全量目标中的一个检查点。

新增实际阅读组包括作者介绍、出版社简介及原作节选，分别限定各字段的支持范围。例如《德维什之屋》的出版社宣传和节选介绍给出不同故事年份，暂不填入故事时间；根据已读节选，分别讨论警务关联归罪和儿童身体照护中的自主。合集只归纳已辨明的篇目或组织方式，不把某一篇的情节套给全部篇目。

同时修正 `Q134060310` 的当前出版纪年：原始书目误记 1815 年，原刊 *The Electrical Experimenter* 的 1915 年 11 月目录、署名、页眉和章节标题对应到 Hugo Gernsback 的 “Münchhausen Lands on Mars”。更正为 `1915-11`，原始 `1815` 仍保留在来源层和差异记录；网站筛选与排序使用更正值。这项依据来自原刊 PDF 的文本提取，未将其记作像素检查或整条作品核验。更正与实际查读范围见 `research/content-corrections.json`。

## 第四轮检查点

新增 167 条核心分析和 356 个细分问题：早期 21 条、1900—1979 年 76 条、1980 年后或源日期未知 47 条、中文作品与合集 23 条。累计 1,254 条已有核心分析，13,310 条待补；1,102 条有细分问题，共 2,283 个。自本次持续推进开始已新增 470 条分析，仍继续处理剩余队列。

中文组实际读取了《2018年4月1日》的完整教学文本、出版社授权《鲸歌》节选、大学论文中《两只小鸟》的意大利语翻译提案、作者访谈、出版介绍及部分二手梗概。材料性质和所读范围逐来源保存；译文提案、作者回忆、社区梗概及简介均不冒充原刊独立核验。《Invisible Planets》《Broken Stars》是多作者合集，来源作者栏分别只列陈楸帆和夏笳，保留该缺口并提示编者、选篇和整合集范围；《A View from the Stars》含非虚构文章，不作为一条连续小说剧情。

《当恐龙遇上蚂蚁》的较短作品与后来的扩写、《蓝血人》等后续正在处理的拆分版本，以及来源纪年仍有疑点的《Vagabonds》等，均保留文本范围说明。补文学议题不自动改写作者、年份、原语言或现实科学匹配度。

倪匡组区分《蓝血人》与《回归悲剧》、《透明光》与《真空密室之谜》、《妖火》与《真菌之毁灭》等拆分单位；尚未读到上部依据的《妖火》不借下部结局补写。社区情节梗概与出版社简介逐来源标明范围，人物推论、虚构科学及改编差异保留为待核。例如《地底奇人》的地下帮会与《地心洪炉》的地下地理设定分别处理，《沉船》的身体改造解释仍标为叙述者推断。

## 全量队列

`research/issue-research-queue.json.gz` 恰好覆盖全部 14,564 条身份，并保留每条当前核心问题状态、内容资料记录、实际查读日志（有归档时）、缺失字段、文本边界与来源链接。

| 阶段 | 依据与下一步 |
| --- | --- |
| `analysis_present` | 已有核心问题，继续逐字段核对；不代表已全部核实 |
| `content_reading_next` | 已取得简介，先前题名作者对应且此次题名与至少一位作者未变；仍需辨明文本粒度和内容 |
| `identity_then_content` | 有简介，但身份或范围存在待核项；先区分同名、系列、合集、短篇或版本 |
| `source_search_next` | 定向资料中没有简介；继续查原作、作者、出版社及图书馆内容资料 |

队列依据当前资料状态排序下一步，不能替代逐条阅读。每部作品详情显示其任务与已取得资料状态；网站补全页显示当前筛选范围的四类数量。

时间长廊的各时代同时显示“当前条件匹配数”和“底库数”，底库数仅保留前史与边界开关。空间、研究层级、搜索和年份状态都有可清除的筛选标记；清除单项时保留当前视图。例如宇宙尺度筛选中 1800 年以前为 0 个匹配，但底库仍有 33 条早期记录，其中 28 条空间待分类。这些数量描述当前输入实体，不是全球出版统计。

## 复现

1. 运行 `scripts/acquire-work-synopses.py`，传入官方月度 dump URL 和仓库外缓存目录；流式处理，不保存整份 dump，不进行数千次逐本 API 请求。
2. 运行 `scripts/index-reading-materials.py`，传入仓库外缓存和仓库外阅读索引路径；生成公开事实清单与私有待研读资料包。
3. 实际阅读资料，把带身份和字段依据的解释记录在 `research/issues-*-roundN.json`。自动登记脚本按轮次加载，原批次与原解释均保留。
4. 依次运行 `scripts/build-completion.mjs` 与 `scripts/build-unified.mjs`，再运行所有验证脚本，包括 `scripts/validate-reading-queue.mjs`。

完整统一下载保留于 GitHub 的 `research/canonical-universe.json.gz`。网站按每千条拆分无损副本，分片清单为 `dist/assets/canonical-universe-manifest.json`，以适应持续增长及单个资源大小限制；验证会重组所有分片并与完整快照逐项比较。
