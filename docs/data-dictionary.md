# 数据字典

本字典说明统一底库中的来源书目、已有研究与空间依据。它们共享作品身份，但证据层次不同，不能将统一记录数表述为全部“已研究科幻小说”数量。旧研究目录及来源导出分别保留，以便复核原始字段和版本。

## 当前统一浏览模型

`research/canonical-universe.json.gz` 保存统一索引及研究层；完整来源对象由来源下载与详情分片另行保留。所有主要视图使用同一统一 ID，旧研究 ID 通过别名解析。完整架构见 [统一底库](unified-architecture.md)。

| 字段 | 含义与限制 |
| --- | --- |
| `id` | 来源 QID，或未可靠链接研究的 `local:<研究ID>`。没有按显示题名去重。 |
| `research_id` / `source_id` | 可空；分别指已有研究与来源记录身份。 |
| `research` / `source_index` / `entity_link` | 研究层、来源轻索引和实体链接依据；来源完整详情另行加载。 |
| `topics` / `research_topics` / `topic_candidates` | 联合检索议题、研究解释和来源规则候选；证据层分开存储。 |
| `branches` / `source_subject` | 联合检索值及原始来源题材。联合标签不表示每个来源类别均已人工确认为科幻分支。 |
| `research_level` | `researched`、`candidate`、`bibliographic`；分类候选不是研究完成。 |
| `first_year` / `sort_year` / `source_first_year` | 研究纪年优先用于浏览；来源最早年份候选单独保留。整数或 `null`，未知不为 0。 |
| `year_display` / `year_note` | 显示年份与版本口径，须与数值年一起阅读。 |
| `languages` / `forms` | 联合保留研究与来源显示标签；来源语言声明不等于已核原语。 |
| `spatial_primary` / `spatial_evidence` | 有研究依据时沿用阅读层，否则 `unknown`；不是物理位置。 |

URL 筛选的 `yearStatus` 为 `known` 或 `unknown`；留空表示不限定。年份范围筛选排除未知纪年，未知筛选不会为记录人为造年。时间轴以年度数量聚合，列表分页，不为每条作品堆叠图表元素；年度密度只代表当前底库及筛选结果。

## 研究目录：`research/catalog.json`

顶层对象为 `{ "metadata": { ... }, "works": [ ... ] }`。`metadata.record_count` 当前为 168；`inclusion_counts` 区分 160 条科幻作品、5 条科幻前史和 3 条混合与边界参照。`form_counts` 按所收录文本形态计数，`coverage`、`method`、`year_rule`、`limits` 保留方法边界。

| 字段 | 类型 | 含义与使用限制 |
|---|---|---|
| `id` | 字符串 | 稳定目录记录标识，如 `early01`。不等于 ISBN，也不表示质量排序。 |
| `title_zh` | 字符串 | 中文检索名，可含常用译名别名；未有统一译名者可能采用已注明的工作译名。 |
| `title_original` | 字符串 | 识别原作的原题或原题／通用英语识别名；应结合语言与版本备注，不能假定所有条目都是英语原作。 |
| `author` | 字符串 | 作者检索显示名，可含合作作者。不是经过规范化拆分的个人实体数组。 |
| `first_year` | 整数 | 所收录文本形态的主要出版版本年，不必是全球最早公开事件。前史记录可能使用已明确注明的排序占位。 |
| `year_note` | 字符串 | 连载、单行本、原型、翻译、自出版、修订、题年／发售年及存异说明；与年份一起使用。 |
| `year_display` | 字符串 | 面向阅读的约年或版本表达，例如“约 2 世纪”。不得强行解析为单一精确年份。 |
| `sort_year` | 整数 | 网站排序和历史导航用年；通常等于 `first_year`，少数采用重要连载年，不是统一的首发字段。 |
| `language_tradition` | 字符串 | 原作语言及文学／出版语境的组合标注；不是国籍或地理坐标。 |
| `form` | 枚举字符串 | 本条所记文本形态。见下表。 |
| `inclusion_status` | 枚举字符串 | 科幻作品、科幻前史、混合与边界参照；是本项目的收录边界判断。 |
| `topics` | 字符串数组 | 十二个可交叉的底层议题；为本项目分析，不是来源原生题材字段。 |
| `branches` | 字符串数组 | 为比较和检索使用的重叠分支标签；不表示作者当年的自称或唯一类型。 |
| `story_era` | 字符串 | 故事发生的时代或历史关系，如近未来、架空过去、文明末期；不提供精确起止日期。 |
| `duration` | 枚举字符串 | 主体叙事历时的保守粗分；不能从故事所在年代或宇宙背景直接推算。 |
| `reach` | 字符串 | 回忆、框架、跳跃和远期展望中的最大时间视野。这里记录时间，不记录空间大小。 |
| `issue` | 字符串 | 撤掉表层装置后仍成立的核心问题，通常一句；为原创比较分析。 |
| `science_class` | 枚举字符串 | 主要叙事前提与当前知识的关系，不是文学分数或未来成真概率。 |
| `science_note` | 字符串 | 说明主要科学假设、现实基础及未证／反事实部分；优先阅读此解释，避免只看标签。 |
| `sources` | URL 字符串数组 | 实际用于核查的作品、作者、出版社、图书馆或研究来源。链接不表示来源替全部标签背书。 |
| `evidence_note` | 字符串 | 划分书目信息、设定依据与本项目推断，指出未完成核查及争议。 |
| `series_name` | 可选字符串 | 相关系列识别名；存在此字段不表示整套系列各卷均已收录或继承同一时间跨度。 |

### 枚举与多标签

| 字段 | 当前取值 |
|---|---|
| `form` | 长篇、中篇、短篇、组篇小说、系列、前史叙事 |
| `inclusion_status` | 科幻作品、科幻前史、混合与边界参照 |
| `duration` | 日—月、年—一生、多代—百年、千年—文明史、百万年—宇宙尺度、多尺度或非线性、待核 |
| `science_class` | 近现实外推、依赖未证技术、强反事实设定、混合或不适用 |

“多代—百年”包含数百年量级；“多尺度或非线性”描述结构而非固定长度；“待核”保留证据不足，不能在分析时当作零时长。“百万年—宇宙尺度”是时间粗档名称，不表示已经获得天体空间定位。

`topics` 的十二个值为：知识与认识、生命与人类定义、主体与意识、权力与制度、资本与劳动、殖民与他者、生态与资源、时间与因果、文明与历史、生存与风险、技术与责任、性别与亲密。

最终目录目前使用 23 个 `branches` 标签：硬科幻、社会科幻、太空歌剧、赛博朋克、后赛博朋克、生物朋克、气候科幻、灾难与末世、反乌托邦、乌托邦、女性主义科幻、时间旅行、平行世界与另类历史、第一接触、军事科幻、后人类、宇宙演化、科学奇幻、科幻前史、机器人与人工智能、新怪谭与混合类型、蒸汽朋克、太阳朋克。标签可随后续核查修订，不能用当前样本频数估计世界出版分布。

### CSV 与 JSON 的关系

[catalog.csv](../research/catalog.csv) 含 UTF-8 BOM，方便表格软件识别中文。每行对应一条研究记录；数组用 ` | ` 连接，列名为中文。它包含主要研究字段，未导出 `year_display`、`sort_year`、`series_name`。因此需要保留约年显示或排序口径时，应读取 JSON，不能从 CSV 的整数年重建全部版本语义。不要直接按 `|` 分割整行，应先使用标准 CSV 解析器处理引号、逗号与换行。

## 扩展候选书目

当前完整查询返回 14,534 个成员，14,532 条进入索引，2 条明确非虚构记录另存 `research/expanded-excluded-records.json`。按来源 QID 保留版本、章节、系列边界，不按题名删除或合并。

| 完整字段 | 含义 |
|---|---|
| `source_labels` / `source_aliases` | 全部取得的语言标签与别名，保留语言键；显示名不等于已核原题。 |
| `title_statements` | P1476 的题名及语言字串。 |
| `author_entities` | 作者 QID、名字与来源实体；可获得的其他语言标签另集中保存于 `related_entities`。 |
| `publication_dates` | 所有取得的 P577 直接日期声明；日期精度和版本语义未独立核实。 |
| `language_statements` | P407 语言声明，不自动等于原作语言。 |
| `source_types` / `source_subject` | P31 类型与 P136 分支／题材声明，保留实体编号与显示名。 |
| `source_entity_kind` | 来源类型提示的版本、章节、系列或其他单位边界，不表示完成了作品身份归并。 |
| `relationships` | P179 系列、P361 组成、P155 前作、P156 后作、P144 基于、P747 版本／翻译；完整保留方向、目标 ID 与取得的标签。 |
| `topic_candidates` / `branch_candidates` | 可解释规则产生的候选；每项保留 `basis` 来源字段、原值、命中文本、实体与 URL。不是人工核查标签。 |
| `genre_hierarchy_refs` | 引用独立的完整分支谱系；不在每条记录重复所有祖先。 |
| `narrative_time` / `reality_future_fit` | 为后续研究保留的结构字段，本次扩展来源缺乏相应证据，明确留空待核。 |
| `detail_url` | 轻索引指向完整详情分片的同源路径，只是载入方式，不是内容删减。 |

`research/expanded-catalog.json.gz` 保存完整来源导出；`research/structured-bibliography.json.gz` 在其上增加候选分类，保留每条原始字段。网站先载入轻索引供全量检索，再按需获取完整详情。`dist/assets/bibliography-full.json.gz` 无损压缩上述完整结构化记录。验证脚本逐条对比原字段及所有详情分片，防止字段因网站优化丢失。

`genre-hierarchy.json` 包含 454 个直接标签、1,176 个祖先／自身节点、1,965 条 P279 直接边。泛类也原样保留；来源层级并非本项目创建的唯一文学分类体系。

扩展来源是 Wikidata；成员规则和抓取口径见 [方法说明](methodology.md)。候选数据只是外部书目声明，网页浏览器使用下列规范字段。原始来源可能另保留更丰富的声明，不能据此提升为逐条已核研究。

| 浏览字段 | 类型 | 含义与限制 |
|---|---|---|
| `id` | 字符串 | 来源 QID；按此去重，不按显示题名误合并。 |
| `title` | 字符串 | 显示题名，优先来源中文／英语标签或标题声明；显示标签不自动等于原题。若只剩 QID，意味着题名缺失。 |
| `authors` | 字符串数组 | 来源作者姓名或作者实体显示标签；可能缺失、不完整，或只剩实体 ID。 |
| `first_year` | 整数或 `null` | 所导出 P577 日期的最小年份候选；未经独立核实，不是已确认全球首发年。`null` 表示未知。 |
| `source_url` | URL 字符串 | 指向对应 Wikidata 实体，供进一步核对声明与来源。网页仅接受 HTTP／HTTPS 链接。 |
| `subjects` | 字符串数组 | 来源题材／体裁标签；应称为“来源主题标签”，不自动转换成本项目的科幻分支。 |
| `edition_count` | 非负整数或 `null` | 来源若提供的版本数；本次 Wikidata 查询没有统一的全量版次数，通常为 `null`。 |

未附着研究的来源层保留书目待核；统一视图另区分已有研究、规则候选与基础书目。原始语种与文本形态未核时，不能用英语显示标签、条目所属主题或一本译版替代未知。

来源导出可能附带的字段及解释如下：

| 来源字段 | 解释 |
|---|---|
| `wikidata_id`、`key` | 实体 QID 与实体 URI；保留身份，不证明两个不同 QID 一定是不同原作。 |
| `title_zh`、`title_en`、`display_title_language` | 显示标签及其语言，不是作品原始语言。 |
| `title_original` | 原题未独立核验时保留 `null`。 |
| `title_statements` | P1476 标题文字及其语言标签；一条声明的语言不代表整部作品已核原语。 |
| `publication_dates` | 来源所导出的 P577 日期声明集合；精度、版本和限定语还需核对。 |
| `first_publish_year`、`first_publish_year_candidate` | 与 `first_year` 同口径的候选显示字段，不是增加了一次独立核查。 |
| `original_language` | 原始语言未独立核验时保留 `null`。 |
| `language_statements` | P407 作品或名称的语言声明，保留来源原义，不自动确认为原语。 |
| `author_entities` | 作者实体 ID、姓名标签与来源 URL；与自由文本作者姓名共同用于检索。 |
| `source_subject`、`source_types` | 来源 P136 题材与 P31 类型实体；可能出现系列、组篇、剧本等边界。 |
| `openlibrary_work_ids` | 来源已有的 Open Library work 标识，不表示本次另从该平台全量抓取。 |
| `verification_status`、`analysis_status` | 保留书目待核、未进行深层议题／空间／全文分析的状态。 |

候选元数据中的 `source_total`、`fetched_count`、`excluded_count` 分别表示来源查询返回总量、实际抓取数和筛除数；页面实际载入数从当前 `records` 数组计算。导出层也可能使用 `source_entity_count`、`metadata_record_count`、`record_count`、`exclusion_count` 表达相应环节。缺失字段显示未知，不能默认为零；这些数都不是全球科幻作品总量。

## 空间导航数据

`dist/assets/spatial.json` 是原始研究空间导航层，顶层含 `metadata`、`zones`、`works`，通过研究目录的 `id` 关联。统一模型沿可靠实体链接映射到统一 ID；缺少研究依据的记录以 `unknown` 保留，不能仅因为进入同一底库而继承空间标签。

| 字段 | 类型 | 解释 |
|---|---|---|
| `id` | 字符串 | 对应 168 条研究目录中的记录 ID。 |
| `primary` | 分层 ID 字符串 | 主阅读层，仅用于网站摆放。 |
| `secondary` | 分层 ID 数组 | 现有研究明确支持的其他场域或背景，可为空。 |
| `rationale` | 字符串 | 依据已有研究记录作出的定位理由或保留意见。 |
| `confidence` | 枚举字符串 | 明确、暂定；表示导航依据的把握程度，不是概率分数。 |

分层 ID 为 `earth`（地球／社会）、`planetary`（地月／行星）、`interstellar`（恒星际／深空）、`galactic`（星系／文明网络）、`cosmic`（宇宙／演化）、`abstract`（抽象／未定／多维）。其中“行星”不只指太阳系天体，“文明网络”不保证覆盖整个银河，“抽象”也不表示作品没有物理场景。

作品光点的空间位置、距离、大小与轨道是界面布局，不在此研究字典中作为真实坐标或天体数据定义。查阅空间理由时，不能把发表年、长时演化或时间旅行误读为物理距离。

## 缺失、争议与修订

研究目录中的“待核”“未量化”“版本存异”与候选中的 `null` 都具有实质含义。分析时应保留这些状态，不得自动填入零年、英语、长篇或某个分支。字段修订应同时保留条目身份、文本形态、来源链接和证据备注；原始输入与最终目录之间的差异见 [归档说明](../research/source-notes/README.md)。
