# 补全与独立核对

本轮以补全为目标：把熟悉作品的已知内容写入可查询字段，并为每条作品、每个字段登记缺失和证据状态。当前底库14,564条均保留，结构检查覆盖17个字段。这只保证当前来源集合逐条登记，不能据此宣称全球全部科幻或每条都完成文学内容核验。

## 四层数据及其证据

1. **原来源层**：完整Wikidata快照、题名声明、作者、日期、语言、分支、系列与版本关系等原样留存。展示题名不自动成为原题，语言声明不自动成为原语。
2. **原研究层**：168条首轮书目与主题研究记录、已存来源和版本备注均保留。未可靠链接的32条使用local身份；来源相似不能强行合并。
3. **知识补充层**：熟悉作品的空间、叙事时间、底层议题、分支、科学前提、原创核心问题、原语等选择性补充。每字段带知识依据与边界，标为“已有知识补充，待独立核对”。来源链接本身不是对新增全部字段的核验。
4. **外部对照层**：Open Library作品索引的题名、作者、最早年份候选、版本数量、主题词、关联语言和场所等单独保留。通过定向批量检索既有P648标识取得，不下载小说正文。主题词规则候选保留完整命中值、规则和URL。

基线字段审计单独固定归档；补全层和当前统一快照反映补充后的状态。字段状态、缺口和冲突可通过网站全站筛选与“补全进度”浏览，跨视图不更换作品集合。

## 外部实体粒度保护

Open Library作品记录汇总多个版本，返回的language是版本语言集合，不代表原语。first_publish_year只能作为外部书目候选，不能直接宣布初刊事实。接口说明见 [Search API](https://openlibrary.org/dev/docs/api/search) 与 [使用指引](https://openlibrary.org/developers/api)。

仅候选单部小说且来源只有一个、未与其他源实体共用的P648 W标识，在题名与至少一位作者相符后，允许生成主题词候选或填原本缺失的年份候选。作者全部共同作者、连载／单行本、版本地区和原语仍需独立核对。

共享标识、单篇与合集、扩写长篇、系列、版本、未知粒度、题名作者不对应以及未返回记录，都列为身份／粒度待核。例子包括《献给阿尔杰农的花》的1959短篇与1966长篇、《安德的游戏》的1977短篇与1985长篇、《出卖月亮的人》的单篇与合集。这些实体均保留各自ID，并禁止从可疑对应继承年份和主题。

未对应实体的年份不列成本作品日期冲突。只有可靠部分书目对应后的日期差异、或原研究与来源的日期差异才进入“日期或版本有差异”。双方值保留，差异本身不能证明哪一方错误。

## 状态与缺口

字段状态区分：来源转录、原研究资料／解释、已有知识补充、规则候选、部分书目跨来源一致、外部年份候选、信息缺失、尚未确认与存在差异。各类均不等于整条完成独立核验，`source_verified`本轮保持false。

“待补全”包含缺失及原题／原语尚未确认；已有规则候选计为有记录，并单列候选数量，仍需要文学研究。泛化的“文学作品”不视为具体文本形态已确认；明确来源描述可给出“长篇”“短篇／中篇”“合集／组篇”等形态候选，原始源类型保留。来源未给关系不表示作品没有系列，未知与“不适用／不存在”不混同。

科学前提是与当前知识关系的定性解释，不是未来预测命中率。已有现实技术对应、社会解释力和未来情境稳健性尚未为每部作品建立独立实证矩阵。叙事时间从剧情知识补充，绝不由发表年份推测；文学空间绝不由时长或题名猜测。

## 继续补全

先选择缺失字段或身份待核集合，再为具体条目提供字段值、对应实体粒度、证据URL／页码及核对范围。独立核对应该逐字段记录，不以一个整条标签替代事实、版本和文学解释的差异。所有原始值、旧判断、变更依据和来源字段都保留，以便持续纠错。

## 底层议题的补充与查阅

底层议题区分三种内容：12类宽泛导航主题、具体作品的核心矛盾分析，以及更细的问题与情节依据。来源体裁/主题词最多生成第一种候选，不能据此认定作品已有核心问题分析。界面将未整理分析显示为“议题分析尚未补充”；这不是对作品本身或研究者熟悉程度的判断。

每条细分分析保存 `label`（保留原始细分标签）、`question`（要比较的问题）、`basis`（作品的具体设定或情节依据）。议题批次只修改议题相关字段，不连带推断空间、叙事时间或科学匹配。单篇、扩写长篇、合集和系列仍保留独立身份；集合记录只讨论集合层面的主题，不把某一篇情节冒充全部内容。

新增分析均标为已有知识补充、待独立核对；依据是可复核的剧情概括，尚非带原文页码的核验。只有实际查阅的资料URL才加入来源，链接不能替代逐字段确认。每批文件及完整原始断言归档；已有分析保持显示值，新的不同解释单列为补充解释。

议题地图的数量、例子及细分标签随全站条件更新。`issueStatus=analyzed/missing` 分别查询有无核心问题分析；`facet` 精确查询原始细分标签。全站搜索也能检索问题与情节依据，URL跨视图保留筛选。相近细分标签尚未进行强制同义归并，便于后续研究时保留细枝末节。原始源标签和规则候选另存，不由文学解释覆盖。

实际发现的源题名错配等疑点以原始断言中的 `identity_caveat` 保存，并在卡片与分析详情显示。分析明确对应的文本名称不会自动替换源题名；需另行核查源标签与实体身份。

本轮交叉复查的检查范围、有限定向原作/出版社来源、具体错配及修正、仍待核的题名层级保存在 [`research/issue-review-notes.json`](../research/issue-review-notes.json)。这是补充批次的内容质量检查，不是全库逐本或逐字段独立核验；所有新增解释仍保持待核。
