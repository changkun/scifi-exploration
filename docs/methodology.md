# 研究方法与边界

研究日期：2026 年 10 月 4 日。项目用于建立科幻文学的系统知识地图，并讨论技术、人类与文明的可能未来。网站以统一作品身份承载来源书目、来源规则候选和已有研究解释，所有主要视图共用作品集合与筛选状态。证据层分开保存，不再作为两套互不联动的浏览库。架构见 [统一作品底库](unified-architecture.md)。

## 统一底库与证据层

**初始研究目录共 168 条**：160 条科幻作品、5 条科幻前史、3 条混合与边界参照。目录包含 133 条长篇、15 条中篇、5 条短篇、8 条组篇小说、2 条系列与 5 条前史叙事。这里的“条”是目录记录单位，不是全部单卷、单篇或版次的数量。系列记录和单部记录不能直接当作同一出版统计单位。正式归档见 [研究报告](../research/report.md)、[JSON 目录](../research/catalog.json) 与 [CSV 目录](../research/catalog.csv)。这些文件保留首轮研究的历史版本与论述范围，后来的扩库和统一身份没有将其改写成全量研究报告。

研究目录是全球取向的选择性样本，覆盖古代前史至 2025 年出版的作品。它不是人类历史上所有科幻小说的穷尽清单，也不提供各语言、国家或分支的真实出版占比。初始168条研究目录没有系统纳入2026年新书；后续统一底库的近期补充及尚未发表的预告范围见[持续补全记录](continuous-issue-research.md)。

**扩展书目来自 Wikidata，均为候选、尚待逐条核查。** 查询筛选在来源知识图谱中具有科幻题材及文学作品类型路径的实体：

```sparql
SELECT DISTINCT ?work WHERE {
  ?work wdt:P136/wdt:P279* wd:Q24925 .
  ?work wdt:P31/wdt:P279* wd:Q7725634 .
}
```

该集合反映来源在抓取时的声明和分类层级；它不保证实体一定是小说，不保证全部是互不重复的独立作品，也不能补齐来源没有登记的文学传统。来源查询总量、已抓取数量、排除数量及实际载入数量应分别报告，并以发行数据的元数据和网页当前显示为准。本方法说明不把开发阶段的空数据或探针数量写成完成数量。

来源书目按 Wikidata QID 去重，避免因同名而误合并不同作品。相同作品仍可能对应多个实体，作品、版本、系列或组篇的边界需人工核对。已有研究通过可复核的实体链接附着到统一记录；证据不足或实体粒度不同的研究条目以 `local:<研究ID>` 保留，旧研究 ID 继续作为别名使用。来源 QID 与本地记录尚可能存在待核重叠，因此统一记录数也不是全球唯一作品数。

只有可靠链接的统一记录才能沿用其研究议题、故事时间、空间层或科学判断。题名相似不能自动建立链接；原始来源值、规则候选和研究解释各自保留。各主要视图与比较使用统一 ID，搜索、年代、年份状态和其他筛选由同一状态管理；`yearStatus=known` 与 `yearStatus=unknown` 分别表示有可用纪年和未知纪年。指定年份范围时排除未知年，不把 `null` 转成 0。

## 来源与核查层次

研究目录主要使用《科幻百科全书》（SFE）的作者、历史与主题条目，辅以作者资料、出版社介绍、图书馆书目和少量可直接读取的原文。现实技术对照优先采用科研论文与机构一手资料。每条 `sources` 与 `evidence_note` 保留支持范围及争议。

本次完成的是书目研究和主题综合，没有对全部原著逐本全文细读，也没有建立逐章、逐场景事件表。书目、设定和文学史语境有来源支持；`issue`、`topics`、`branches`、`science_class` 及多数时间粗分是本项目的比较解释。来源页面包含某部作品，并不意味着该来源认可本项目给出的全部标签。

原始研究输入与笔记保存在 [source-notes](../research/source-notes/README.md)。输入合计 166 条，最终将《三体》的聚合记录拆为三卷并作独立分类，形成 168 条；最终目录还包含整理阶段的修订。归档输入用于追溯，不覆盖最终目录。

## 首轮补全的调度

为尽快扩大有依据的内容覆盖，四路按互斥作品ID并行。先扫描各自剩余目录，能准确记起具体内容的作品直接用已有知识补入并标待核；再一次采用现成且题名、作者对应的明确简介。陌生身份每个只做一次精准查询，按8—16条批量并发，返回足够材料立即补入；准确来源入口只有目录时最多再直接读取一次。仍然过短、失败、错配或需要反复浏览器操作的条目如实记原因并后置，不追加本轮搜索。从近往远用于同一优先级内，实际失败轮次越多越靠后；后置条目始终保留在全量队列，深读和独立核对另继续进行。

每次构建在[全量研究队列](../research/issue-research-queue.json.gz)保留每条的priority与全部未分析ID的priority_order，失败计数依据实际归档轮次，不能把未查过记成失败。只补来源支持的原创议题、具体问题和情节依据，新增解释均为knowledge_added_unverified。取得简介、字段有值及完整独立核验是不同状态；不通过降低证据要求提高完成率。

## 出版年与版本

研究目录的 `first_year` 对应**本条实际收录的文本形态及主要出版版本**，通常优先单行本；短中篇通常使用原刊年，系列通常记录首卷。它不必是全球最早公开事件。连载、原型短篇、手稿、自出版、外语首译、扩写、修订和商业再版是不同事件，差异记录于 `year_note`。

`sort_year` 主要用于网站历史导航，少数记录采用已核的重要连载年；它不是另一套统一的全球首发年。`year_display` 保留约年和版本差异。卢奇安《真实的故事》的 `170` 是排序占位，可靠表述为“约 2 世纪”，不能据此做精确的年度出版统计。某些作品的版本年份仍存异，目录明确保留争议。

扩展书目的 `first_year` 仅为该 Wikidata 实体所导出的 [P577 出版日期](https://www.wikidata.org/wiki/Property:P577) 中最小年份候选，尚未独立确认它指原作初刊、单行本、译本还是其他版本。日期中的 `01-01` 也可能是精度占位，不能直接当作精确出版日。

## 时间、议题与分支

扩展书目新增可复现的 `source-label-rules-v1` 分类入口，规则位于 `scripts/enrich-bibliography.py`。只匹配来源原始分支、可追溯的分支祖先标签与来源说明，不根据书名或作者身份猜测。候选保存命中文本和来源字段，供人工确认、反驳或修改。当前 1,147 条有底层议题候选，13,385 条缺乏足够规则证据，保留待分类；规则候选覆盖率不是研究完成率。

全量原则是保留成员索引、原始字段、细分标签、版本关系、缺失状态与排除记录，再逐来源扩展。当前完成的是已声明 Wikidata 查询的完整导出，未声称全部全球科幻作品及其底层议题已经核查完毕。更多完整索引的接入状况与访问限制见 [来源覆盖](coverage-sources.md)。

`story_era` 描述故事所在时代；`duration` 粗分主体经历的时长；`reach` 描述回忆、历史背景、框架和远期展望打开的最大时间视野。出版年份、人物经历、外部世界经过的时间和系列背景必须分开。抵达千万年后的时间旅行，不表示人物经历了千万年；地球、银河和多宇宙是空间概念，不能代替时间视野。

议题和分支采用多标签。同一作品可以同时讨论生命、劳动、制度和生态，也可以同时属于社会科幻、第一接触与太空歌剧。前史、后人类、生物朋克等标签有时是回顾性检索工具，不表示作者在创作时使用或接受了该术语。来源题材词、作者国籍、原始语言、作品发生地与文学语境均不能相互替代。

来源层的 `subjects`／`source_subject` 保留题材标签；统一浏览可联合来源题材与研究分支检索，但应保持来源身份与依据，不能将所有原始题材一律认定为已核科幻分支。中文或英语显示标签也不能证明作品的原始语言；[P407](https://www.wikidata.org/wiki/Property:P407) 是作品或名称的语言声明，仍须核对版本与声明对象。

## 现实与未来匹配

本项目采用定性比较，不给整部作品一个未经校准的“预言准确率”或成真概率。四个问题分别是：科学前提与当前知识的关系、后来技术是否有具体功能对应、社会机制是否有解释力、未来情境在改变前提后是否仍成立。

168 条目录逐条完成的是科学与工程前提的粗分类及解释；另外三维主要在报告框架和八组案例中展开，尚未为每部作品建立完整实证矩阵。“硬科幻”不等于全部可实现；“近现实外推”不表示全景已经得到验证；形而上或前史叙事也不能硬套成现代科学正确性评分。

## 3D 空间导航

空间导航是基于已有研究记录的**阅读分层**，不是天体位置数据库。它参考 `story_era`、`issue`、`branches`、`reach`、`science_note` 与证据备注，分为地球／社会、地月／行星、恒星际／深空、星系／文明网络、宇宙／演化、抽象／未定／多维。

每条空间记录保留主层、次层、理由与“明确／暂定”的把握程度。长寿、百万年历史、社会科幻、第一接触或太空歌剧标签本身均不足以推出具体天体。“明确”表示现有记录足以支持该阅读层，不表示剧情或物理坐标已完整核验。

网站中作品光点的摆放、距离、轨道和大小用于交互与视觉组织，不是现实坐标、宇宙距离、发生概率或作品价值的量化结果。主题关系也不能当作真实宇宙中的邻近关系。可靠链接到空间研究的统一记录可沿用其依据；其余记录进入空间待分类区，不能从题名、发表年或分支推断其天体位置。

提交研究更正时，应给出稳定条目 ID、原题、待改字段、支持来源与版本信息。扩大目录时，先确认作品与版本身份，再补来源、议题及时间尺度；不以扩大数量替代证据。原始输入、最终目录与候选数据层应各自保持可追溯性。


### 已发现误读的显式更正

议题解释被新阅读证据纠正时，先保留原冻结输入与散列值，在 `research/issue-corrections.json` 单独记录目标身份、原组件、错误主张、更正理由及实际读取范围。构建逐项校验精确旧断言后采用修正展示；原字段另存 `superseded_issue_fields`，逐批 `assertions` 仍保留原文。详情明确显示更正记录，更正不增加作品或细分问题计数，也不升级独立核验状态。


### 2026-10-04：先做快速覆盖，再加深复核

首轮对题名和至少一位作者对应、内容明确的现成简介一次读取，先提取作品特定的简短核心、底层议题和两项带情节依据的问题。没有具体剧情、简介错配或卷次不明时直接记原因并延后；不为补空间、结局或精细解释反复查读。四个互斥身份分片独立推进，一批扩大至约40–60份可用简介。切换前实际读过的其他来源仍按范围归档。

简短首轮补充继续标作 `knowledge_added_unverified`，不是全文阅读或独立核验完成。未披露信息留未知，原有细节与冻结输入不削减；后续按字段逐步加深及复核。已有身份获得新分析时保存新断言和依据，不重复增加核心覆盖计数。

完整补全档案始终在仓库保留。网站按实际字节大小拆分完整记录，分片不改变身份顺序或内容；完整压缩下载若超出单个托管资源上限，下载入口改为仓库中的同一完整档案，浏览视图仍加载全部记录。

### 开放分类适用于所有研究维度

分类法是可修订的研究结果。`research/classification-registry.json` 登记新分类的稳定编号、维度、定义、版本、相关议题、精确作品身份和逐作品依据，生成统一数据与网站所用的同一注册表。议题、研究分支、叙事机制、时间经验、空间组织、科学设定机制、现实与未来关系、表达形态均可新增、拆分和关联。跨度与科学关系的字段值也允许登记扩展；未知仍保持未知。 这项原则适用于网站所有内容，包括作品资料、议题分析、年代导航、宇宙地图、科学前提、比较、历史路线和补全队列；新增维度采用统一作品身份和来源范围，不因现有菜单或固定选项而丢弃发现。

暂定研究分支与原来源体裁分别记录；空间组织与地图尺度、时间经验与发表纪年及故事跨度、科学机制与科学可行性分别记录。原字段、来源和细分问题保留。第一版26个入口的53条人工种子只示范有依据的关联，不以标题关键词自动扩散到全目录；未关联表示尚未整理，聚类数量不计作核心补全或独立核验。

新增分类在所有视图使用统一身份与筛选状态，支持跨维度交集、链接往返及结构化下载。“新增”只相对于本项目既有框架，不声称是文学史上首次出现的概念。原断言被纠正时保存精确目标及更正依据，可显式替换错配的议题，旧断言继续归档。


### 2026-10-06：八个维度的可浏览新入口

V22在原39个暂定入口上增加10个有逐作品依据的比较入口：惩罚与生活目的、身体治理研究分支、读者与观众参与规则、跨时访问权限、多重世界连通、生命与心智战备存档、创作者经历转写、虚构世界指南、虚构与非虚构同册编排、异常报告的真实性包装。28条新关联保留选篇、版本、目录、作者自述和来源范围；原158条发现候选与细分机制不改写。新增导航不是原作全文或现实技术核验，Stars and Gods仅取得目录形式入口，核心问题仍待补。

空间补充同时复用已有准确知识和已保存的有限场景资料，独立登记地点与理由；没有明确地点或距离时继续保留未知。一般形式或出版信息、同系列他作、题名中的星系或宇宙不能替代本条目的具体舞台依据。

### 2026-10-06：从核心分析扩展作品的描述维度

本批为40个已有核心分析的统一作品实体补充141项记录：叙事机制、故事关键设定和现实关联各40项，故事时域17项，表达形式4项。全部仍是已有知识补充，待独立逐字段核对；这141项不增加核心分析条目、实际查读次数或独立核验数量。单篇、长篇扩写和系列单卷分别保留，未用某一成员代表合集，也未将影视改编替代原文学实体。

`narrative_mechanism`描述作品如何组织信息、冲突与行动；`scientific_premise`记录故事规定的关键条件，不评定技术是否可实现；`reality_relation`是文本与现实问题之间的文学比较，不是预言准确率、现实实验结论或作者创作史证据；`expression_form`描述表达结构，不覆盖来源的小说、短篇或其他文本形态。17项`story_era`沿用故事时代字段，以作品内背景、相对阶段或并行时层说明，具体纪年不明时保留待核。出版年、背景千年、人物经历和主体故事时长仍分别记录。

四个新增描述字段各有独立状态和缺口统计，可以在详情、比较与全文搜索中查阅；“已有记录”表示存在可追溯描述，不表示已经核实。来源或分析尚不能支持的字段仍为空，不能由题名、体裁、发表年或同系列其他作品批量填入。科学可行性原字段和原17项基线审计继续保留，不因取得设定描述而自动变为已补齐或已验证。

本批逐字段保存原公开分析文件、原记录与活跃议题断言的精确引用，并明确解释范围。原链接按原分析的支持范围保留，本批未再次查读，不能把它们升级为新增五维的独立证据。原初分析未登记的owner、查读日志、缓存和次数保持未知；“本次没有新请求”与“原来从未查询”是两件不同的事。

八轴导航中的议题、研究分支、叙事、时间、空间、科学机制、现实关联和表达形式可以随具体证据新增或细分入口。新增入口要说明适用文本、具体作品依据与不适用的边界；研究分支不直接等同公认文学体裁，空间组织不直接等同距离尺度，科学机制不直接等同科学可行性。作品资料、年代、地图、比较、阅读路线和补全队列均使用相同作品身份与依据范围。新分类或新描述不以标题关键词自动传播，旧定义、旧标签、候选与修订记录继续保留。
